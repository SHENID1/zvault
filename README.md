# 🛡️ ZCode Secret Masking Proxy (Zero-Leak LLM Gateway)

Локальный защитный шлюз для клиента **ZCode**, который полностью устраняет риск утечки токенов и секретов при работе с непроверенными или сторонними («нн») LLM API.

---

## 🎯 Как это работает

```
ZCode (Ваш редактор)
       │  (Запрос с кодом / промптом: sk-live-98765...)
       ▼
[Локальный Прокси 127.0.0.1:8765]
       │  1. Перехватывает messages
       │  2. Заменяет реальный токен на __VAULT_API_KEY_01__
       │  3. Сохраняет маппинг в локальной памяти
       ▼
Неизвестный LLM API (agentrouter.org / китайские реселлеры / VPS)
       │  Видит ТОЛЬКО плейсхолдер __VAULT_API_KEY_01__
       │  Реальный токен НИКОГДА не покидает ваш ПК!
       ▼
[Локальный Прокси 127.0.0.1:8765]
       │  4. При стриминге SSE ответа на лету заменяет
       │     __VAULT_API_KEY_01__ обратно на sk-live-98765...
       ▼
ZCode (Ваш редактор)
       Получает рабочий готовый код с вашими настоящими ключами.
```

---

## 🚀 Быстрый старт

### 1. Запуск прокси
Просто запустите файл:
```cmd
run.bat
```
Или в терминале:
```powershell
python server.py
```
Прокси поднимется на `http://127.0.0.1:8765`.

---

## ⚙️ Настройка ZCode

В ZCode в настройках провайдеров (или в файле `~/.zcode/v2/provider_config.json`) измените `baseUrl` нужного провайдера:

### Вариант А: Именованный маршрут (Рекомендуется)
Если в `config.json` прописан upstream (например, `"agentrouter": "https://agentrouter.org/v1"`):
* **Было:** `https://agentrouter.org/v1`
* **Стало:** `http://127.0.0.1:8765/agentrouter/v1`

### Вариант Б: Универсальный маршрут (Без правок config.json)
Для любого нового сервиса без перезапуска прокси:
* `http://127.0.0.1:8765/proxy/https/<целевой_домен>/v1`
* Например: `http://127.0.0.1:8765/proxy/https/agentrouter.org/v1`

## 🔒 Что защищается автоматически:
1. **Автодетект по регулярным выражениям:**
   - OpenAI / Anthropic (`sk-...`)
   - GitHub PAT (`ghp_...`, `github_pat_...`)
   - Telegram Bot API токены (`\d{9,10}:...`)
   - AWS ключи (`AKIA...`)
   - SSH/RSA приватные ключи (`BEGIN PRIVATE KEY`)
   - Пароли в строках подключения к БД (`postgresql://user:pass@host`)
2. **Статические секреты (`secrets.json`):**
   Вы можете явно вписать любые токены, которые не должны покидать ваш компьютер:
   ```json
   {
     "MY_CUSTOM_SECRET": "любой_секретный_текст_или_пароль"
   }
   ```
3. **Domain Binding (Защита от SSRF):**
   Прокси проверяет белый список хостов (`allowed_hosts` в `config.json`). Попытка отправить запрос на неразрешённый хост блокируется кодом `403 Forbidden`.
